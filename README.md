# 💬 Whatsapp newsletter (Selenium)

Скрипт на Python для автоматической отправки сообщений через **WhatsApp Web**.  
Работает на **macOS**, **Windows** и **Linux** с помощью фреймворка **Selenium**.  
Поддерживает отправку по **номерам телефонов из CSV-файла**.

---

## ⚙️ Возможности
- 📤 Автоматическая рассылка сообщений по списку номеров  
- 📁 Загрузка контактов и текста сообщений из `contacts.csv`  
- 🔐 Авторизация через ваш профиль Google Chrome  
- 💬 Поддержка длинных сообщений с переносами строк  
- 🧹 Автоматическое закрытие чата после отправки (опционально)

---

## 🔧 Как использовать

### 1️⃣ Подготовьте файлы проекта
Перед запуском убедитесь, что в папке проекта находятся два основных файла:

- **`whatsapp_bulk_send.py`** — главный скрипт для рассылки сообщений  
- **`make_contacts_csv.py`** — вспомогательный скрипт для генерации CSV-файла с контактами

Проверьте файлы, и настройте под себя для дальнейшего использования!

---


### 2️⃣ Сгенерируйте файл контактов

1. Откройте **Терминал** (или **Командную строку**).  
2. Перейдите в папку с проектом:
   ```bash
   cd ~/Desktop/Рассылка
3. Запустите генератор:

- python3 make_contacts_csv.py или python make_contacts_csv.py

После запуска создастся файл contacts.csv
В нём автоматически появятся столбцы:

phone,message

— где phone — номер телефона, а message — текст для отправки.

### 3️⃣ Установите зависимости

- Если вы ещё не устанавливали пакеты, выполните команды:

- pip install --upgrade pip
- pip install selenium webdriver-manager pandas


- 📘 В папке проекта уже есть инструкции для каждой ОС:

- INSTRUCTIONS_MAC.txt
- INSTRUCTIONS_WINDOWS.txt
- INSTRUCTIONS_LINUX.txt

- Следуйте соответствующей инструкции для вашего устройства.

## ⚡️ Пример рабочего процесса
- make_contacts_csv.py  ➜  contacts.csv  ➜  whatsapp_bulk_send.py  ➜  WhatsApp Web  ➜  Автоматическая рассылка


## ⚠️ Важно

- 🚫 Не отправляйте слишком много сообщений подряд — **WhatsApp** может временно ограничить ваш аккаунт.  
- 🌐 Для стабильной работы **не закрывайте браузер** во время рассылки.  
- 🔐 Скрипт использует **ваш текущий сеанс Chrome**, поэтому **QR-код нужно сканировать только один раз**.  
- ⏹ Если хотите остановить рассылку — просто **закройте окно терминала или браузера**.
